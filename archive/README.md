# Архив расширений Glassify

Сюда переносится целая папка `extensions/<id>/` со всеми версиями, превью и дополнительными файлами. Для расширения должна существовать запись в `catalog.json`.

После попадания переноса в `main` GitHub Actions обновит пути в каталоге и укажет коммит с архивной копией. Glassify 0.6.0-beta.21 и новее покажет расширение в разделе **Расширения → Архив**. Файл по-прежнему можно установить после проверки SHA-256 и Git blob.

Архив фиксирует последнюю опубликованную версию. При переносе сохраняйте содержимое файлов и версии.
